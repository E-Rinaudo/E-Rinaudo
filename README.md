## 🚀 Projects & Learning Journey

I've been learning programming on my own through books, courses, and lots of hands-on practice. Each project represents a step forward in my journey.

- **[Games & Data Visualizations](https://github.com/E-Rinaudo/first-solo-projects):**  
  While studying Python Crash Course, I created several small games and data visualizations using libraries like `pygame`, `matplotlib`, and `plotly`.
- **[thermo-tracker](https://github.com/E-Rinaudo/thermo-tracker):**  
  A command-line utility I built for my family to track radiator heat usage and organize data in Excel files.
- **[cosmic-standoff](https://github.com/E-Rinaudo/cosmic-standoff):**  
  A CLI-based turn-based strategy game where you play as a spaceship captain against an alien opponent.

These projects reflect my learning progress. With each new project, I aim to improve on the last and expand my knowledge.
